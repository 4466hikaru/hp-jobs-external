# job-015 notes — 地域中ボス5体（姫ではない）

0819 UI色世界（黒鉄 / ルビー=危険のみ / アンティークゴールドは一点）と喧嘩しないよう、各体のアクセントは炉の熱・灯・錆に限定した。装飾の盛りはしていない。

## 01 草原 門番型 — 土橋の巨像（`01-grassland-gatekeeper.png`）

- 役割: 草原の峠道そのものを塞ぎ、許可なく通る隊を踏みとどめる門番。
- 攻撃1: 両脚を門柱のように開脚したまま踏み込み、道幅いっぱいに地響きを走らせて転倒させる。
- 攻撃2: 上体を前に倒して「閉じる」——腕を門扉代わりに叩き下ろし、通路を物理的に封鎖する。
- シルエット狙い: 道の正面から見てΠ型。脚の間が通行可能な隙間に見え、通ろうとした瞬間に塞がる。

## 02 雪原 塔守型 — 霜鉄の物見（`02-snowfield-tower-warden.png`）

- 役割: 雪原の物見を一人で歩く。遠方の侵入を先に捉え、塔に報せる前に食い止める。
- 攻撃1: 頭頂の氷visorから氷杭を斉射（塔のスリット射撃の身体化）。
- 攻撃2: 胴を軸に一回転し、凍気の輪で足元の雪をガラス化して移動を封じる。
- シルエット狙い: 縦長の二脚。肩が胸壁、頭が物見窓。横に広がらず「塔が歩いている」読ませ。

## 03 砂漠 隊商喰い型 — 砂舟の顎（`03-desert-caravan-eater.png`）

- 役割: 砂漠の隊商路に潜み、荷と護衛ごとすくい飲む伏兵。
- 攻撃1: 甲羅状の砂板を前に滑らせ、砂を噛んで前方へ吐き出す埋没波。
- 攻撃2: 頭部を覆うスクープ状の甲を地面に押し、隊商を船体の顎ですくい込む。
- シルエット狙い: 低い横長。背は砂丘、頭は荷をすくう船首。四脚で「歩く砂の舟」。

## 04 湿地 沈殿型 — 沈砂池の躯（`04-wetland-sediment.png`）

- 役割: 湿地の水路を澱ませ、足場を沈めて獲物を沈殿槽へ落とす。
- 攻撃1: 周囲の地面を軟化させ、円形の沈下ゾーンを作る（槽の縁が足場）。
- 攻撃2: 胴の堰板を開き、溜めた泥と水を前方へ噴出して視界と移動を奪う。
- シルエット狙い: 裾の広い台形。上が槽、下が脚柱。沈殿池が脚で立っている。

## 05 火山 炉心型 — 炉の核（`05-volcano-hearthcore.png`）

- 役割: 火山の熱源そのものが歩いている。炉を守り、近づくものを焼き、鉱滓にする。
- 攻撃1: 腹の炉心を露出させ、短い熱パルスで正面を焦がす（チャージ後に胸が赤く点く）。
- 攻撃2: 脚元へ鉱滓を落とす範囲灼熱。接地した円がしばらく残る。
- シルエット狙い: 丸く低い樽。頭は炉口、腹は炉室。横に張らず「歩ける窯の核」。

## 正直な申告

- Cursor の GenerateImage ツールが executor から呼べなかった。スクリーンショット切り出しは使わず、text-to-image（pollinations zimage）で1体ずつ生成した。job-002 のグレードA画質（1024幅の絵画的立ち絵）には届いていない。解像度は 768²、JPEG由来のPNG。
- **01 門番が一番苦手。** 「身体が門」はモデルがほぼ建物か人体に割れてしまい、納品は「峠を塞ぐ石の巨像」に寄せた。白背景ではなく草原と空。スケール用の人影が小さいが残っている。
- **02** は塔そのものではなく、氷鉄の二脚ゴーレム。肩=胸壁の読ませはノート側。白〜グレーのスタジオ背景。
- **03** は正面寄りだが完全正面ではなく、スクープ甲が横顔気味。砂の獣としては一番役割が読めた。
- **04** は5体中もっとも「役割型の生きた構造物」。ただし純白ではなく霧の湿地。吊り苔がやや多い（動かせるデザインとしては減点）。
- **05** は窯・煙突の構造物ではなく、炉心が肉身化したコンパクト体。腹の赤は熱であり流血のつもりではないが、傷口に見えうる。
- パレットは黒鉄・炭・地域の土色。ルビー相当は 02 の visor と 05 の炉心のみ。金の支配的使用はしていない。
