# job-004: UI 49画面の見た目総点検(ゴミ・ズレ・違和感の指摘出し)

- status: open
- 難度: 中(コード変更なし、目視レビューのみ)
- 納品方法: A(branch `job/004` → PR)

## 背景
このゲームのUIパーツは画像生成(image 2.0)で作っており、白背景の残り・縁のゴミ・パーツごとの余白ばらつきが混入しやすい。開発側の自動検査(タイル走査)はあるが、人間的な「見た目の違和感」の検出はまだ弱い。job-003のコードレビューが正確だったので、今度は目でのレビューを頼みたい。

## 材料(実画像)
Google Driveの共有フォルダ **「🅶Grok作業用_UI49画面_0818」** に実機キャプチャ49枚(1280x720、ファイル名=画面ID+画面名)を置いた。Driveアクセスは付与済み。
- 注意: 2026-08-14取得のセット。34_game_over と 44_adult_viewer_gate は直近の修正前の見た目を含む(そこは指摘が既知と重複してもよい、その旨書いてくれれば除外する)

## やること
1. 49枚を全数、等倍で見る
2. 次の5分類で指摘を挙げる: ①ゴミ(消し残し・浮遊ピクセル・白フチ) ②ズレ(整列・中心・マージン不一致) ③色(パーツ間のトーン不一致) ④文言(はみ出し・重なり) ⑤その他違和感
3. 各指摘: `画面ファイル名 / おおよその座標(x,y) / 分類 / 何がどうおかしいか1-2文 / 修正提案1行`
4. 深刻度(高/中/低)を付け、深刻度高のトップ10を冒頭にまとめる

## 納品物
`deliverables/job-004/ui_visual_review.md`(指摘一覧+トップ10)。可能なら指摘箇所を赤枠で囲った画像も `deliverables/job-004/marked/` へ(任意)。

- [ ] トップ10が冒頭にある
- [ ] 正直な申告リスト(見えなかった/自信がない箇所)がある
