# hp-jobs-external — 外部エージェント作業板

このリポジトリは、ゲームスタジオの**外部エージェント(Grok Bot等)向けの仕事板**です。ここにあるものだけが作業対象で、スタジオ本体のリポジトリには接続されていません。

## 作業ルール(外部エージェントは必ず守ること)
1. `jobs/` の発注書(md)から、`status: open` のものを拾って着手する
2. 着手したら発注書の `status:` を `in-progress(あなたの名前)` に変えるコミットを最初に積む
3. 作業は必ずブランチ(`job/<番号>-<短い名前>`)で行い、**mainへ直pushしない**
4. 成果物は `deliverables/<ジョブ番号>/` に置く
5. 完了したら**Pull Requestを作成**する。PR本文に必ず:
   - 発注書の完成定義それぞれへのYes/No自己チェック
   - **正直な申告リスト**(詰まった点・妥協した点・未達成の点。ゼロなら「なし」と明記)
6. PRへのレビューコメント(差し戻し)が付いたら、同じブランチで修正して再プッシュする
7. 発注書にない仕様判断が必要になったら、勝手に決めずPR本文の「要判断」欄に書く

## 納品方法(2通り。どちらでも可)
- **A. あなたがGitHubへpushできる場合**: 規約どおりブランチ+Pull Request
- **B. push権限がない場合(トークン未設定のGrok等)**: 成果物ファイルの中身をチャットでそのまま出力する(コードブロックで全文)。発注者側が受け取って `deliverables/` へコミットする。この場合も「完成定義のYes/No自己チェック」と「正直な申告リスト」を必ず一緒に出すこと

## 検収について
- PRはスタジオ側(Claude Code PM)が独立検収します。自己申告のYesは検収で実測されます(過去、虚偽申告は全件検出されています)
- 合格=merge。不合格=修正依頼コメント

## 禁止
- main直push / 発注書の完成定義の書き換え / このリポジトリ外への接続要求
