## 2. 姫=武器ビルド：実装契約と受入基準

この節は `spec_princess_weapon_build_v1.0` の決裁済み本文を、実装タスクがそのまま引用できる形で固定する。ここにない価格式、リロール、ロック、wave時間、属性相性・耐性・状態異常、完成UIアートは本仕様の対象外である。

### PB-REQ（データ契約）

| ID | 仕様（2026-07-22） |
|---|---|
| PB-REQ-01 | 各ラン内武器インスタンスは `ownerCompanionId`、`weaponDefinitionId`、`tier`、`attributes`、`attackRole` を持つ。攻撃の発生元は所有姫。 |
| PB-REQ-02 | 姫ごとの武器枠は4。同行3人なら最大12同時武器を許容。制限は実測パフォーマンスだけ。 |
| PB-REQ-03 | 報酬/店の候補は編成姫の属性と交差する武器だけ。属性効果は一致属性ダメージ増だけ。 |
| PB-REQ-04 | 候補は `targetCompanionId` を持ち、獲得時にその姫へ自動装備。姫を選ぶ手動配分UIは禁止。 |
| PB-REQ-05 | 獲得直後、同一`weaponDefinitionId`を低Tierから2本→次Tier1本へ反復。異種/異属性は合成しない。 |
| PB-REQ-06 | 主人公の武器枠は0。アイテム/防具/ペット等の非武器は共通インベントリに無制限で保持/適用。 |
| PB-REQ-07 | 旧装備セーブを変換しない。新スキーマは旧`subEquipment`/主人公武器を参照せず、無効な旧データを持ち込まない。 |
| PB-REQ-08 | ダンジョン報酬 `companion_slot_2/3` により同行枠を1→2→3へ更新・保存・UI表示。 |

### PB-AC（完成定義）

| ID | Yes となる条件 | 現状 |
|---|---|---|
| PB-AC-01 | 同行3人×各4、計12武器を固定seed・リリース解像度・60秒で60fps（16.67ms/frame以下）維持。build ID、解像度、敵数、平均/1% low/最悪frame timeを保存。 | `[未実装]` 12武器ランの所有・性能試験がない。 |
| PB-AC-02 | 同条件ログで一致属性ダメージだけが設定倍率分増え、耐性/相性/副次効果0件。 | `[未実装]` 属性契約の実装証跡なし。 |
| PB-AC-03 | 7姫の単独/複数編成固定seedで、非編成属性専用武器0件、全候補に対象姫ID。 | `[未実装]` 候補絞込/対象姫IDの実装証跡なし。 |
| PB-AC-04 | Tier1×4+Tier2×2の獲得で、Tier1→Tier2→Tier3の順で自動合成するテスト。 | `[未実装]` 低Tier合成コード/テストなし。 |
