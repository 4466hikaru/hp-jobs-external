# 20-06 ラウンド制・中間帰還仕様

> 版: v1.0 / 作成: 2026-07-28 / 状態: B案採択済み。数値バランスは仮（プレイテスト調整予定）。
>
> 主読者: 実装・ゲームデザイン・QA。根拠: game repo `67b5ae9` の`project.json`、`dungeons.json`、`Main.gd`。

## 20-06-01 目的

ダンジョンを「短いwaveを越えるたびに、今確定する安全な帰還か、ビルドを保って危険な次waveへ進むか」を選ぶBrotato準拠のループにする。帰還画面は演出ではなく、報酬・損失・次の危険を読んだ上で選べるゲーム上の決定点である。

## 20-06-02 現行フロー（実装事実）

```text
dungeon_info → round N を生存 → round_result/choice
  ├ 続ける → Lv・武器・バフを保持して round N+1
  └ 帰る → 獲得済み報酬を確定し、carryoverを保存して町へ
最終boss round → clear または game_over
```

| 項目 | 現行値・挙動 | 状態 |
|---|---|---|
| round数 | ダンジョン1〜3は3、4〜7は4 | 実装済み |
| 1roundの秒数 | 120〜180秒 | 実装済み |
| 中間帰還 | 最終以外の`canReturnAfter=true`で可能。Esc/Bは帰還。 | 実装済み |
| 続行時 | レベル、武器、バフを保持。次roundの敵構成へ進む。 | 実装済み |
| 帰還時 | round報酬を保存、`partialReturnRewardIds`を補い、町へ戻る。 | 実装済み |
| 中断セーブ | `midDungeonSaveInitiallyEnabled=false`。inter-round onlyはplannedで、各roundも`canSaveAfter=false`。 | 未実装 |
| streak倍率 | 現行配列`[1.0, 1.3, 1.7, 2.2]`。round完了数に応じて報酬倍率を表示。 | 実装済み |
| 帰還carryover倍率 | 全7ダンジョンで`0.45`（仮・プレイテスト調整予定） | B案採択値 |
| 完走時の追加 | `continueRewardMultiplierPerRound=0.10`（仮・プレイテスト調整予定）。carryoverは完走時、基礎率×深度×`1.0+0.10×(完了round-1)`で計算。 | B案採択値 |
| `continueCarryoverBonusPerRound` | 全ダンジョン`0.02`をデータが保持する。 | 使用経路の回帰テスト要 |

帰還画面は「獲得済み」「次wave名・秒数・推奨Lv」「続行時倍率」「帰還時の恒久引継%」を出し、初期フォーカスは続ける。これは実装事実であり、意図的な初期選択として維持するかはUI理想一致QAで再確認する。

## 20-06-03 固定・変動・損失境界

| 区分 | 固定 | 変動 |
|---|---|---|
| ループ | wave終了時に継続/帰還の二択、最終bossでは帰還不可 | round数、時間、敵構成、報酬 |
| 継続 | 現在のラン内Lv・武器・バフを保持 | streak倍率、次waveの危険度 |
| 帰還 | 既に獲得したround報酬を確定して町へ | partial reward、carryover対象・倍率 |
| 敗北 | 未確定分を失う。`failRewardIds`のみが敗北報酬候補で、carryoverの計算対象は`return/clear`のみ。 | ダンジョン別failReward |

同一roundの報酬は`applied_dungeon_round_reward_indices`により一度だけ付与する。帰還・入力連打・再描画で二重付与してはならない。

## 20-06-04 採択済みリスク・リターン仕様（数値は仮）

帰還45%、続行ボーナス+10%/roundのB案を採択する。以下の数値はすべて仮（プレイテスト調整予定）であり、プレイテスト前に恒久値として扱わない。比較条件は「同一seed・同一ビルドでR1帰還、R2帰還、完走」を各ダンジョンで100回ずつ記録すること。

| 案 | 帰還carryover | 完走追加 / round | streak | 狙い | 懸念 |
|---|---:|---:|---|---|---|
| 現行読取値 | 55% | +8% | 1.0 / 1.3 / 1.7 / 2.2 | 仮の実装アンカー | 価値・損失の体感が未検証 |
| A 安定探索（仮） | 65% | +6% | 1.0 / 1.20 / 1.45 / 1.75 | 初見でも帰還が死に選択にならず、探索を回しやすい | **不採用** |
| B 深追い勝負（仮） | 45% | +10% | 1.0 / 1.35 / 1.85 / 2.45 | 「もう一波」を明確に得にする | **採択**。数値はプレイテスト調整予定 |

採択方針は、P0の初見プレイでもBの深追いの快感を優先すること。数値調整後の恒久値と個別例外はプレイテスト結果を別途記録する。

## 20-06-05 テスト観点

| ID | Yesとなる条件 |
|---|---|
| R-T-01 | 7ダンジョン25roundで、非最終roundだけに帰還導線があり、Esc/Bと画面ボタンの結果が一致する。 |
| R-T-02 | 続行後もLv・武器・バフが保持され、敵/弾/画面オーバーレイだけがround境界の仕様どおりに切り替わる。 |
| R-T-03 | 帰還・連打・再ロードで各round報酬が一度だけ保存され、町へ到達する。 |

| R-T-05 | 採用案の固定seed計測で、R1/R2/完走の期待値・敗北率・平均時間を保存し、案の狙いに反する支配戦略がない。 |
